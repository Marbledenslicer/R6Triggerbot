# R6 Triggerbot

Download: soon

Triggerbot for Rainbow Six Siege with delay and zone control.

| Setting | Range |
| --- | --- |
| delay | 20–120 ms |
| zone | 2–8 px |
| pulse | 5–20 ms |
| visible only | on/off |

Load as administrator, start the game, F8 to toggle. 40 ms delay is the middle ground.

Windows 10/11 · Ubisoft Connect · BattlEye.
